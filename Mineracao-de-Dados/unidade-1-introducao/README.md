# Introdução à Mineração de Dados (aula sem código)

Sessão de estudo de 03/11/2026. Unidade I. Anotações de estudo.

## Conceito de Data Mining

Fornece percepções dos dados corporativos, descobrindo padrões e relacionamentos ocultos em grandes bancos
de dados e inferindo regras a partir deles para prever comportamentos futuros. Esses modelos e regras podem,
então, ser utilizados para guiar processos de decisão e prever o efeito dessas decisões.

## Técnicas e algoritmos de análise de dados

1. "Eu quero encontrar relacionamentos entre ações ou itens" -> **Regras de Associação**;
2. "Eu desejo agrupar itens dadas as suas similaridades" -> **Clustering**;
3. "Eu quero encontrar o relacionamento ou valor específico de uma variável dada uma entrada" ->
   **Estimação de valores ou Regressão**.

## O processo KDD e suas fases (só a que caiu na prova)

O KDD é composto por etapas sequenciais essenciais para o sucesso de projetos de Inteligência de Negócios
(BI) e Mineração de Dados.

- **Mineração de Dados** -> fase do processo KDD que se relaciona com a execução efetiva dos algoritmos e
  técnicas de análise de dados e reconhecimento de padrões.
