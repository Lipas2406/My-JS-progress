# Algoritmos de Regressão e Classificação (aula sem código)

Sessão de estudo de 14/11/2026. Unidade IV. Anotações de estudo.

## 1. Conceito e etapas de classificação

- Analisa e procura as melhores características para classificar uma série de categorias ou classes.
- Para criar um classificador, é preciso uma etapa de treinamento inicial, com um conjunto de dados de classes
  previamente conhecidas. Aí o classificador se torna capaz de associar novas instâncias desconhecidas às classes
  estabelecidas.

## 2. Regressão linear e predição numérica

- Técnica utilizada para prever valores numéricos contínuos a partir de dados de entrada.
- Regressão linear simples: `y' = mx + b`.
- Serve para prever valores e comportamentos futuros baseados em tendências históricas.

## 3. Exemplos de algoritmos de classificação

- Classificadores probabilísticos e baseados na Teoria de Decisão de Bayes.
- Classificadores lineares baseados em funções de probabilidade.
- Classificadores baseados em redes neurais, métodos estocásticos e classificadores polinomiais.

## 4. O algoritmo Naïve Bayes

- É um classificador probabilístico fundamentado na Lei de Bayes e nas suposições de independência condicional.
- O algoritmo assume que a presença ou ausência de uma característica específica (atributo) de uma classe não está
  relacionada com a presença ou ausência de qualquer outra característica.
