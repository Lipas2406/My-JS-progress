# Introdução ao Desenvolvimento .NET e Visual Studio (aula sem código)

Sessão de estudo de 27/11/2026. Tópicos Especiais em ADS, Unidade I. Anotações de estudo.

## 1. Herança em VB .NET (`Inherits`)

- Orientação a objetos em VB .NET: quando uma classe herda características de outra, eu tenho que utilizar a
  palavra-chave `Inherits` logo após o nome da classe.
- (Nota: em Java, usa-se `extends` para herança de classe e `implements` para interfaces, enquanto `herança` e
  `heritage` não são palavra reservada do VB .NET.) (copiado e colado)

## 2. Comparações entre Java e VB .NET na orientação a objetos

- **Metodologia de programação:** as duas se parecem muito, desde as classes até os métodos.
- **Ambientes de desenvolvimento:** utilizam ambientes diferentes, tipo NetBeans para Java e Visual Studio para o
  VB .NET.
- **Herança múltipla e execução de classes:** nenhuma das duas possui herança múltipla direta de classes, e não tem
  como um projeto de uma rodar na outra.

## 3. Definição de blocos em Java e em VB .NET

- **Java:** `{` para o início e `}` para o fim de um bloco.
- **VB .NET:** ao invés de `{}`, é por palavra literal mesmo: `If ... End If`, `While ... End While`,
  `Select Case ... End Select`, `Sub ... End Sub`, `Function ... End Function`, `Public Class ... End Class`.

## 4. Similaridade da plataforma .NET

- A plataforma .NET é similar à plataforma Java, pois ambas oferecem diversos serviços e ambientes estruturados para o
  desenvolvimento de aplicações.
- Java só usa a linguagem Java, mas o .NET pode suportar várias linguagens, como VB, C#, C++ e J#, compiladas para
  MSIL e executadas em um ambiente gerenciado pelo CLR.
